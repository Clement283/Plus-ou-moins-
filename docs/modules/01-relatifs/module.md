# Module 1 — Relatifs (identifiant `calculs`, cours 0 à 7)

*Statut : écrit et en ligne (cours 0 à 7). Révision des nombres relatifs (collège) : calcul sans erreur de signe, sans calculatrice. Cours 0 à 3 : plus de fiche (le contenu est dans le code et ses tests).*

## Points importants du module
- **À la fin, l'élève sait** : écrire un calcul proprement ; additionner, soustraire, multiplier et diviser des relatifs sans erreur de signe, y compris à plusieurs termes ou facteurs ; vérifier un résultat (opération inverse, ordre de grandeur).
- **Vocabulaire et conventions de l'appli** : un nombre négatif s'écrit entre parenthèses sauf en 1er terme (−3 + (−5)) ; le « − » a deux rôles (opération, signe du nombre) ; **négatifs en orange, positifs en bleu**, jamais de rouge (réservé aux erreurs) ; droite graduée animée ; « l'opposé » d'un nombre.
- **Techniques enseignées** : garder le signe quand il est le même ; « le plus grand sans le signe gagne » ; regrouper les positifs puis les négatifs ; soustraire = ajouter l'opposé ; règle des signes (× et ÷ pareils) ; compter les − dans un produit ; vérifier par l'opération inverse.
- **Limites volontaires** : pas de fractions (divisions qui tombent juste seulement) ; pas de lettres ; niveaux = nombres plus grands et calculs plus longs, bornés par la largeur du téléphone.
- **Sert aux modules suivants** : l'erreur de signe est la première cause de points perdus (équations, second degré, dérivées) ; « je compte les − » prépare (−1)ⁿ et le carré ; la règle des signes de ÷ est reprise pour le signe d'une fraction.
