# Cours 2 — Retirer ou ajouter le même nombre des deux côtés
Module : Équations et inéquations (`docs/modules/02-equations-inequations/module.md`) · Précédent : cours 1 « Tester si un nombre est solution » · Sources : cycle 4 p. 10 ; seconde 2026 p. 8 (a + x = b) ; Éduscol, « Résolution des équations, méthode accessible » (balance, transposition à éviter).

## Points importants
- À retenir : (1) ce que je fais d'un membre, je le fais de l'autre ; (2) je fais l'opération contraire du nombre collé à x (x + 3 : je retire 3 ; x − 3 : j'ajoute 3) ; (3) je calcule l'autre membre avec les relatifs, puis j'écris x = …
- Pièges : changer un seul membre (x = 7 pour x + 3 = 7 − 3…) ; mauvais sens (10 au lieu de 4) ; signe du résultat quand le membre de droite est plus petit (4 − 9).
- Vu dans ce cours : balance, « des deux côtés », opération contraire, ligne « opération » (x + 3 − 3 = 7 − 3), x tout seul.
- Écarts et choix : x + b = c seulement, b de signe quelconque ; x et c entiers, négatifs à partir du niveau 2 ; équations en noir ; plus de série de pratique ni d'« Autres façons de faire ».
- Dans l'appli : déroulé guidé, 8 écrans avant l’annonce de la fin (exemple guidé compris) ; `essais/equations-ajouter-retirer.ts` ; l'exercice garde c − b dans `expr` et l'équation dans `meta` (b, c).

## Fiche
### Structure du cours (déroulé guidé)
1. Deviner x dans x + 3 = 7 (ne compte pas).
2. Règle 1 : la balance (x + 3 = 7, on retire 3 des deux plateaux).
3. Règle 2 : l'opération contraire (x − 3 = 5, on ajoute 3) ; petite question sur x − 4 = 9.
4. Règle 3 : le membre de droite plus petit (x + 9 = 4, résultat négatif) ; petite question sur x + 8 = 3.
5. Comparer deux cas : x + 3 = 7 contre x − 3 = 7 (retirer ou ajouter), sur place.
6. Exemple guidé : x + 6 = 2 avec l'aide du cours affichée d'office, non noté.
7. Annonce de la fin, puis 5 exercices « À toi de résoudre » (niveau 1), fiche mémo.
### Règles (3) et erreur évitée
1. Ce que je fais d'un côté du signe =, je le fais de l'autre (`un-seul-cote`).
2. Opération contraire du nombre collé à x (`mauvais-sens`).
3. Je calcule l'autre membre avec la règle des signes (`signe-calcul`).
### Niveaux
1 : b de 2 à 9, x de 1 à 9, c positif · 2 : b de 10 à 30, x et c de −30 à 30 · 3 : b de 10 à 99, x de −99 à 99.
### Hors catalogue
Rien. Formats de révision : `saisie` et `resoudre`.
