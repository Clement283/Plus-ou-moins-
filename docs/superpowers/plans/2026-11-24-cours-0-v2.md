# Cours 0 version 2 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer le Cours 0 par la version 2 validée (leçon pas à pas, petites questions, Réécris, Toucher la faute en bas d'écran), et montrer clairement pourquoi un cours est raté.

**Architecture:** Le moteur (`packages/engine`) gagne deux types de question (`choix`, `reecrire`), un type de partie de leçon (`etapes`, explication pas à pas avec une « scène »), une activité `decouverte` qui ne compte pas, et un repassage propre aux petites questions. Le Cours 0 (`c00-bien-ecrire.ts`) est réécrit avec ces briques. L'appli web (`apps/web`) affiche les nouvelles briques avec les réponses en bas d'écran, puis l'écran de résultat et Mes cours donnent les erreurs par règle.

**Tech Stack:** TypeScript, React 18, Vitest, Playwright (e2e), Cloudflare Worker + D1.

**Spec:** `docs/validation/06-cours-relatifs.md` (partie « Cours 0 », version 2) et `docs/validation/08-decisions-ecrans.md` (n° 20 à 31). Maquette de référence : `docs/design/ecrans/cours-0-v2.html` (textes, ordre, animations ; ouvrir dans un navigateur).

## Global Constraints

- Textes : copier **mot pour mot** ceux du doc 06 (Cours 0 v2) et de la maquette ; signe moins Unicode « − » dans tout texte affiché.
- Couleurs (doc 08 n° 27) : surligneur jaune = « regarde ici » (leçon seulement) ; vert/rouge **seulement après une réponse** ; aucune couleur indicative pendant une question ; pas de couleur de signe dans le Cours 0. Utiliser les tokens de `apps/web/src/theme.css` (ajouter `--highlight` / `--on-highlight` en clair et sombre).
- Tout ce qu'on touche est **en bas de l'écran** (doc 08 n° 28) : choix, cases, clavier, calculs à ranger.
- Clavier de « Réécris » : chiffres 0–9, `+ − × ÷ ( )`, effacer. Jamais réduit.
- Seule la 1re réponse d'un élément compte (doc 01 §6). Les questions `decouverte` ne comptent jamais.
- Quitter un cours = reprendre au début (doc 08 n° 16, inchangé).
- `prefers-reduced-motion` : animations coupées, contenu identique.
- Travail sur `main`, un commit par tâche. Messages de commit en anglais, terminés par les lignes d'attribution de la session.
- Tests : `npm test` à la racine (moteur, web, api, scripts) doit rester vert à la fin de chaque tâche.

## Review Focus

1. Réponse tapée avec espaces, `-` ASCII, `*` ou `x` dans « Réécris » → normalisée, jugée comme la même réponse (Tâche 1).
2. Petite question ratée sur l'avant-dernière partie de la leçon → elle repasse avant les exercices de fin, jamais après (Tâche 2).
3. Événement `activity: 'decouverte'` envoyé au serveur → accepté par `isAppEvent`, ignoré par la note, le suivi et la répétition espacée, compté dans le temps du jour (Tâche 1).
4. Toucher la faute aux niveaux 2 et 3 (nombres à 2 ou 3 chiffres, groupes entre parenthèses) → un nombre = une case, et les cases acceptées sont bien celles de la faute pour les 3 types (Tâche 3, test de propriété sur 500 tirages).
5. Cours validé, ou jamais tenté → Mes cours et l'accueil n'affichent aucune « raison » ; cours raté puis série de validation ratée → la raison vient du dernier essai (Tâche 4).
