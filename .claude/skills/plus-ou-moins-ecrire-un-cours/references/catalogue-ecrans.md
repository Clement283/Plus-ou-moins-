# Catalogue des écrans (tout ce qu'un cours peut utiliser)

L'apparence est **fixée par l'appli** (`apps/web`, design system `docs/design/design-system/`) : un cours ne décrit que du **contenu** avec les briques ci-dessous. On ne touche jamais à `apps/web` pour écrire un cours. Les signatures sont dans `packages/engine/src/courses/calculs/shared.ts` ; ne pas relire ce fichier ni `types.ts` : tout ce qu'il faut est ici.

Tous les helpers s'importent de `./shared`. Toujours `M` (−) dans les textes, `txt(n)` pour écrire un entier (−5), `toText(expr)` pour un calcul en texte, `toLatex(expr)` pour LaTeX.

## Écrans de la leçon (`parts`, dans l'ordre du gabarit)

| Écran | Helper | Remarque |
|---|---|---|
| Accroche + question pour deviner | `texted(decouverte(choix(ex, consigne, options3([libellé, message]…), indiceJuste, calcLatex)), { title, intro: [phrases], mention: NOT_COUNTED_GUESS })` | ne compte pas, ne repasse pas |
| Explication pas à pas | `etapes(titre, [step(phrase, { scene, after, action, rule })…])` | 3 étapes (5 au plus) ; la dernière : `step(undefined, { scene, rule: { n, text } })` |
| Petite question (comptée) | `lecon(small(ex, calcLatex, consigne, [[libellé, message]…], indiceJuste))` | 2 sur un écran : `texted(lecon(…), { joinPrevious: true })` |
| Comparer deux cas | `texted(decouverte(choix(…)), { title, intro, mention: NOT_COUNTED_UNDERSTAND, compare: { a, b, note, highlight, after } })` | **Déroulé guidé** : seulement si deux cas se confondent vraiment ; `compare: { a, b, note: '', highlight, after (2 lignes), inPlace: true }` (surlignage sur place, pas de seconde copie ni de message en double). Ancien déroulé (Relatifs) : B vient du cours précédent, sans `inPlace` |
| Autres façons de faire | `autres({ title, recap, intro, techniques: [{ name, quand, example, how, essai }], outro })` | `essai.kind` : `'saisie'` (valeurs → message) ou `'choix'`. **Ancien déroulé** (Relatifs) : plus utilisé dans le déroulé guidé |
| Série de pratique | `pratique(titre, [{ question, texts: { consigne, intro, above } } ×4], phraseDeTransition)` | notée ; une question du cours précédent. **Ancien déroulé** (Relatifs) : plus utilisée dans le déroulé guidé, les exercices de fin la remplacent |
| Exemple guidé | `etapes('Exemple 1 sur 2', …)` puis `texted(exemple(trou(ex, '= \\square', valeurCachée)), { consigne, above: [lignes LaTeX], help })` | **Ancien déroulé** : aide qui s'efface (exemple 1 presque résolu, exemple 2 : 2 cases). **Déroulé guidé** : un seul exemple, `texted(exemple({ kind: 'resoudre', ex, start, guided: true }), { title, subtitle })` : l'écran des exercices avec l'aide du cours affichée d'office, non noté |
| Annonce de la fin | `annonceFin()` | texte fixe, jamais réécrit |

## Scènes (le haut de l'écran, `scene` / `after` d'un `step`)

- `oneScene('−3 + ', hl('5'))` : un calcul ; `linesScene(['ligne 1'], ['ligne 2'])` : résolution ligne à ligne (la dernière est surlignée).
- `hl('x')` surligne ce dont la phrase parle (jaune, **leçon seulement**). Un morceau peut aussi être `{ t, anim: 'pin'|'bump'|'slide' }` ou `{ t, dim: true }`.
- Autres layouts (`Scene.layout`) : `'row'`, `'pairs'` (mal écrit / bien écrit, avec `tag`), `'line'` (droite graduée : `scene.line = { from, to, jumps:[{from, by, after?}], highlight?, marks?, tone }`).
- `Scene.interval = { intervals: Interval[] }` : un ou deux intervalles coloriés sur une droite graduée sous les calculs (rond plein pour une borne comprise) ; `intervalOfRelation(rel, rat(b))` ou `{ lo, hi, loClosed, hiClosed }` (null = ∞). Exemple : `{ ...linesScene(['x < 3']), interval: { intervals: [intervalOfRelation('<', rat(3))] } }`. Cours 7, 8, 10, 11. Pas dans `compare`.
- `Scene.table = SceneTable` : tableau de signes sans saisie, `{ op: 'seul'|'produit'|'quotient', factors: [{a,b}…], upTo?: 'valeurs'|'lignes'|'signes', rows?: lignes de signes déjà remplies, ghost?: '<'|'<='|'>'|'>=' (colonnes qui conviennent) }`, combinable avec `interval` (lecture de S). Garder au moins une ligne avec `hl` dans la scène `after` d'une phrase à trous. Cours 9 à 11.
- `BuildCtx.index` (0 à 4) : rang de l'exercice de fin, donné à `customQuestion` (absent en révision et en entraînement : prévoir un défaut) ; sert à varier l'aide (`ask` d'un tableau) ou à garantir un symbole.
- `after` : scène montrée dès que l'action est réussie. Sans `scene`, la précédente reste affichée.

## Actions d'une étape (`action`, remplacent « Suite » ; rien n'est noté)

| Action | Écriture |

| Phrase à trous (un seul trou) | `trouOf('… [ ? ] …', ['juste', 'faux'], indiceJuste, { 1: 'message du choix faux 1' })` |
| Je comprends | `{ type: 'comprends' }` (lecture d'une ligne résolue) |
| Toucher une graduation | `{ type: 'graduation', consigne, target, errors: [{ at: [..], message }], fallback }` |
| Toucher un morceau d'un calcul | `{ type: 'morceau', consigne, calc: indiceDeLaLigne, target: [indices de tokens], errors, fallback }` |
| Toucher l'endroit d'un symbole | `{ type: 'endroit', …même forme…, gaps?: [indices d'espaces proposés] }` |

## Questions (comptées sauf `decouverte`)

`saisie(ex)` : taper le résultat. `trou(ex, '= \\square', valeur)` : une case dans une résolution (`above` = lignes déjà posées). `signBox(ex, positif, idErreurSigne)` : boutons + / −. `choix` / `small` : choix en bas de l'écran. `droiteQ(ex, {from,to}, jumps)` : toucher l'arrivée sur la droite. `ordre(ex, étiquettes, ordreAffiché)` : remettre dans l'ordre. `resoudre` (module Équations) : `{ kind: 'resoudre', ex, start: equation(…) }` (`packages/engine/src/math/equation.ts`) ; l'élève écrit chaque ligne en entier (clavier : chiffres, x, + − ÷, = ou < > ⩽ ⩾), avec sa méthode ; chaque ligne est jugée (`judgeTypedLine`), l'opération faite s'affiche sous chaque membre, « Un indice » donne l'étape du cours et marque « avec aide » ; juste si aucune ligne fausse en route (maquette `docs/design/ecrans/equations-resolution-ligne.html`, validée). Construit par le cours (`customQuestion`), pas de générateur commun. `calculer` (module Équations, cours 1 et chaque fois qu'on remplace x par un nombre) : `calculerQuestion(ex, equation(…), x, 'left' | 'right')` (`exercises/calculer.ts`) ; l'élève remplace x puis calcule ligne par ligne (clavier du « Réécris »), puis dit si c'est une solution ; chaque ligne doit garder la même valeur et avancer (`judgeTypedCalcLine`), erreurs reconnues : priorité oubliée, signe ; indice « avec aide ». Juste si aucune ligne fausse en route et 1er verdict juste ; `guided: true` pour l'exemple guidé (indice d'office) ; formats de révision : `formats: ['saisie', 'calculer', 'calculer']` (maquette `docs/design/ecrans/equations-resolution-ligne.html`, état 8, validée). `intervalle` (module Équations, cours 7 et 8, réutilisable pour tout ensemble de solutions) : `intervalleQuestion(ex, '<' | '<=' | '>' | '>=', borne)` pour « x < 3, écris S » (`exercises/intervalle.ts`), ou `intervalleFromInequality(ex, equation(…, rel), { by })` pour une inéquation du 1er degré ; avec `by` négatif, l'élève choisit d'abord le symbole après la division (`flip`, brique `SymbolPicker`), puis écrit S = ] ▢ , ▢ ] : crochets-boutons qu'on retourne, bornes au clavier (touches −∞ et +∞, fractions a/b), droite colorée en aperçu (`IntervalLine`). Une seule réponse jugée à « Valider » ; erreurs reconnues (`math/intervalle.ts`) : crochet fermé contre ∞, bornes à l'envers, autre côté, mauvais crochet, signe de la borne, sens non retourné ; indice « avec aide » ; `guided: true` pour l'exemple guidé ; formats de révision : `formats: ['intervalle', …]`. Construit par le cours (`customQuestion`), pas de générateur commun (maquette `docs/design/ecrans/equations-intervalles.html`, validée le 2026-11-26). `IntervalLine` (droite graduée avec intervalle colorié) et `SymbolPicker` (4 boutons < ≤ > ≥) se posent aussi dans une leçon ou une correction. `tableau` (module Équations, cours 9 à 11) : `tableauQuestion(ex, 'seul' | 'produit' | 'quotient', [{a,b}, …], { valeurs, lignes })` (`exercises/tableau.ts`, facteurs ax + b entiers, valeurs distinctes ; quotient = haut puis bas). L'élève construit le tableau en 3 étapes vérifiées : les valeurs (1re ligne, clavier chiffres − /), les lignes (1re colonne, il écrit le facteur puis l'expression en entière avec parenthèses, ou ÷ pour un quotient affiché en fraction), les signes (palette + − 0, et ‖ pour un quotient). `ask: { valeurs: false, lignes: false }` donne ces étapes toutes faites (signes seuls) ; défaut : tout. Erreurs reconnues : valeurs dans le désordre ou fausses, mauvais facteur, mauvaise ligne totale, signe d'un facteur, règle des signes, 0 oublié ou en trop, double barre oubliée ou en trop ; chaque vérification ratée compte (juste = aucune erreur) ; indice par étape ; `guided: true`. Lire S : `intervalleFromTable(ex, tableau, '<' | '<=' | '>' | '>=')` (`exercises/intervalle.ts`) pose le tableau, colonnes qui conviennent surlignées, et l'élève écrit un ou deux intervalles avec « ∪ Relier un autre intervalle ». `solutions` (cours 6, produit nul) : `solutionsQuestion(ex, [{a,b}, {a,b}])` : S = { ▢ ; ▢ }, deux valeurs dans l'ordre qu'on veut. Composants réutilisables : `SignTable` (tableau présentationnel, `ghost` pour surligner des colonnes) et `TableKeypad`. Maquette `docs/design/ecrans/equations-tableau-signes.html`, validée le 2026-11-26. Formats de révision (`formats` du `CourseDef`) : `saisie`, `droite`, `signe`, `vraifaux`, `erreur` (exemple : `c04-soustraire.ts`).

## Erreurs reconnues

`buildErrors([ErrorSpec…], resolution)` : par erreur, `id`, `family`, `detect(ex, réponseDonnée)`, `text(ex)` (message précis), `draw(level, rng)` (calcul-piège), `sample(ex)` (réponse fausse typique), `alsoWrong?`, `wrongLines?` (résolution fausse). Chaque erreur reçoit `rule: { n, label, partIndex }` : `partIndex` = indice de la partie `etapes` qui enseigne la règle, `label` = son titre exact. Outils : `isOpposite`, `absIs`, `is`, `intOf`, `redraw`, `stepped`, `resultLine`. `feedbackText(q, outcome)` : message par réponse prévisible aux questions qui comptent (`o.correct`, `o.given`, `o.errorFamily`).

## Générateur

`generate(level, rng)` renvoie un `Exercise` (`makeExercise(ID, level, expr)`), réponse **toujours un entier juste**. Le niveau agrandit les nombres **et** allonge le calcul si le cours s'y prête, sans dépasser la largeur d'un téléphone. Les niveaux 2 et 3 servent aux révisions et à l'entraînement ; leçon et exercices de fin : niveau 1. Outils : `draw(rng, [min, max])`, `signs(rng)`, `chain('+'|'*', nombres)`, `SIZES`.

## Hors catalogue ?

Un nouveau type d'écran (graphe, tableau, schéma…) = **mode maquette** : copier la plus récente `docs/design/ecrans/cours-N-v2.html`, ne rien coder avant validation, puis ajouter la brique (composant dans `apps/web/src/components`) **et** une ligne dans ce catalogue pour qu'elle serve aux cours suivants.
